# Theme Name: 轻科技白

# Vibe & Description:
白色基底，天蓝与浅绿点缀，以细线、等宽字体标签、微光指示点和淡网格纹理营造清爽、现代、略带科技感的个人主页氛围。克制不花哨，信息层次清晰。

# Color

- 背景以白色为主（#FFFFFF / #F8FAFC），文字使用深石板灰（#0F172A）、中灰（#64748B）。
- 主色采用天蓝色（#0EA5E9），用于按钮、强调标题、激活态与关键图标。
- 点缀色采用浅绿色（#10B981 / #34D399），用于次要图标、标签、状态指示与分割装饰。
- 卡片使用纯白底配极浅蓝灰细描边，避免大色块铺底；天蓝/浅绿仅小面积焦点使用。

# Font

- 标题与正文使用「阿里巴巴普惠体3.0」，突出科技感与清晰的信息层级。（https://resource-static.bj.bcebos.com/fonts-skill/AlibabaPuHuiTi_SemiBold.ttf）
- 小标签、数字与代号使用等宽字体（ui-monospace），增强科技细节感。

# Animation

- 元素出现时采用“淡入 + 轻微上浮”，时长 300-400ms，保持顺滑克制。
- 交互元素使用轻微缩放反馈（active:scale-95）与颜色过渡，避免生硬位移。
- 微光指示点采用缓慢呼吸脉冲，营造在线状态感。

# Layout

- 页面以白色全屏背景为基础，内容纵向滚动，单列为主，移动端友好。
- Hero 区域突出头像、名字与一句话介绍，背景叠加极淡网格纹理与天蓝光晕。
- 个人信息与数字分身聊天区使用白色卡片纵向排列，间距充足，层次分明。

# Elements

- 按钮使用天蓝实色底配白字，圆角 rounded-lg，配合轻微阴影。
- 卡片使用纯白底、极浅蓝灰细描边、轻微阴影，呈现悬浮质感。
- 科技感细节：等宽字体小标签（如 v1、CS STUDENT）、细线分割、微光状态点、淡网格背景纹理。
- 避免大渐变色块、毛玻璃、霓虹光效与尖锐几何边角。
