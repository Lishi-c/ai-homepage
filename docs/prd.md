# 需求文档

## 1. 应用概述

**应用名称**：个人主页-v1

**应用描述**：从德俊的个人主页，用于向朋友、潜在合作伙伴、面试官展示个人信息，并提供数字分身聊天功能，方便访客了解和互动。

## 2. 用户与使用场景

**目标用户**：
- 朋友
- 潜在合作伙伴
- 面试官

**核心使用场景**：
- 访客通过链接访问个人主页，快速了解从德俊的基本信息
- 访客通过数字分身聊天区提问，获取关于从德俊的更多信息

## 3. 页面结构与功能说明

### 页面结构

```
个人主页-v1
├── 头像区
├── 名字和一句话介绍区
├── 个人信息展示区
└── 数字分身聊天区
```

### 3.1 头像区

**功能说明**：
- 展示从德俊的头像图片
- 位于页面顶部显著位置

### 3.2 名字和一句话介绍区

**功能说明**：
- 展示名字：从德俊
- 展示一句话介绍：一个正在学习用 AI 做产品的大三计科学生

### 3.3 个人信息展示区

**功能说明**：
- 展示以下个人信息：
  - 现在主要在做：整理自己的作品和写作方向
  - 兴趣：PC网游、数码外设
  - 有记忆点的特点：专注力强，善于观察换位思考
- 信息以简洁清晰的方式呈现，层次分明

### 3.4 数字分身聊天区

**功能说明**：
- 提供输入框，访客可输入问题
- 提供发送按钮，点击后提交问题
- 展示数字分身的回复内容
- 数字分身基于以下信息回答问题：
  - 职业或身份：大三计科学生
  - 最近在做的事：搭自己的个人主页，整理作品集
  - 擅长或关心的方向：内容表达、AI 应用、知识整理
  - 常见问题参考：
    - 你现在在做什么？
    - 你有哪些作品？
    - 怎么联系你？
- 聊天记录在当前会话中保留，刷新页面后清空

## 4. 业务规则与逻辑

### 4.1 页面加载规则

- 页面加载时，依次展示头像区、名字和一句话介绍区、个人信息展示区、数字分身聊天区
- 所有内容静态展示，无需后端数据加载

### 4.2 数字分身聊天规则

- 访客输入问题后，数字分身根据预设信息生成回复
- 回复内容需围绕从德俊的职业身份、近期动态、擅长方向展开
- 对于常见问题（你现在在做什么？你有哪些作品？怎么联系你？），数字分身需给出明确回答
- 聊天记录仅在当前会话中保留，页面刷新后清空

### 4.3 移动端适配规则

- 页面需适配手机屏幕，确保在移动端正常显示和交互
- 布局采用响应式设计，内容自动调整以适应不同屏幕尺寸

### 4.4 风格规则

- 整体风格：简约、清爽、稍微有一点古风
- 主色调：红色和浅绿色
- 信息层次清晰，避免过度装饰

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| 访客未输入问题直接点击发送 | 提示「请输入问题」 |
| 访客输入问题后，数字分身无法理解 | 回复「抱歉，我暂时无法回答这个问题，你可以换个方式问问看」 |
| 页面在小屏幕设备上显示 | 自动调整布局，确保内容完整可见 |
| 访客输入超长问题 | 限制输入框字符数量（建议200字以内） |

## 6. 验收标准

1. 访客打开个人主页，页面正常加载，依次展示头像、名字和一句话介绍、个人信息展示区、数字分身聊天区
2. 访客在数字分身聊天区输入问题「你现在在做什么？」，点击发送按钮
3. 数字分身回复「我现在在搭自己的个人主页，整理作品集」
4. 访客在手机端打开页面，页面布局自动适配，内容完整可见且可正常交互

## 7. 本期不实现功能

- 后台管理功能（如编辑个人信息、管理聊天记录）
- 访客留言或评论功能
- 作品集展示模块
- 联系方式展示或表单提交功能
- 数据统计功能（如访问量、聊天次数）
- 多语言切换功能
- 深色模式或主题切换功能
- 聊天记录持久化存储
- 数字分身的高级对话能力（如上下文理解、多轮对话）
