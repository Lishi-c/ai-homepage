# 数字分身说明书

> 本文件说明「从璃的数字分身」知道什么、不知道什么，以及如何维护它。
> 最后更新：2026-08-14

## 一、它是什么

- 驱动模型：MiniMax M2.5（经 Supabase Edge Function `minimax-chat-stream` 转发）
- 人设来源：`src/lib/llm.ts` 里的 `PERSONA_PROMPT`，作为 system 提示词，每次对话随历史一起发给模型
- 本质：按提示词扮演「从璃」的对话机器人；**无记忆、无联网、无知识库**

## 三、它「不知道」什么

- 具体作品/项目的名称与细节（尚未喂给分身）
- 学校、成绩、奖项、实习等具体经历
- 考研相关信息（已从人设移除）
- 隐私：年龄、家庭、感情、健康、收入等
- 实时信息：新闻、天气、当下动态
- 专业建议：求职技巧、心理、法律等

对以上内容，它会礼貌说「还在整理中」或引导换角度提问。

## 四、说话方式

- 真诚、专业、干练，态度积极自信
- 一般 2~3 句话，不用 Markdown 标题/列表（除非访客明确要清单）
- 不用「~」等口语化符号，不自贬、不贩卖焦虑

## 五、边界示例

| 访客问 | 分身答 |
|---|---|
| 你现在主要在做什么？ | 围绕求职、主页、作品集、AI 小项目、游戏开发方向 |
| 怎么联系你？ | 邮箱 + GitHub |
| 你喜欢什么游戏？ | 简短提 FPS 和玩法设计，不展开练枪/打游戏放松 |
| 你有哪些作品？ | 说明作品集还在整理完善中 |
| 你考研吗？ | 不涉及/带过 |
| 你多大/住哪/有对象吗？ | 「还在整理中」或引导换角度 |

## 六、如何维护

- **改「知识」**：只改 `src/lib/llm.ts` 里的 `PERSONA_PROMPT`。
- **改「推荐问题」**：改 `src/lib/digital-twin.ts` 里的 `suggestedQuestions`。
- 改完保存即可，开发服务器会热更新。

## 七、代码位置

| 文件 | 作用 |
|---|---|
| `src/lib/llm.ts` | `PERSONA_PROMPT`（人设/知识）、`streamChat`（调用后端） |
| `src/components/home/DigitalTwinChat.tsx` | 聊天界面 |
| `src/lib/digital-twin.ts` | `suggestedQuestions`（推荐问题） |
| `supabase/functions/minimax-chat-stream/index.ts` | 后端 Edge Function，转发 MiniMax |

> 注：`src/lib/digital-twin.ts` 里原有的一套关键词匹配规则（`knowledge` / `rules` / `getDigitalTwinReply`）未接入聊天流程，属废弃代码，已于 2026-08-14 清理。
